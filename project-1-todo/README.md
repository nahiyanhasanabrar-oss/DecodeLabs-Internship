# 📝 Python CLI Task Tracker

A simple and interactive Command Line Interface (CLI) based task manager built using Python. It allows users to add tasks dynamically and displays the updated task list in real-time until they exit the program.

## ✨ Features
- **Dynamic Task Addition:** Easily add tasks via interactive command-line prompts.
- **Auto-Incrementing Task IDs:** Assigns a unique numerical ID to every added task automatically.
- **Real-Time Task View:** Instantly displays the updated list of recent tasks after each entry.
- **Graceful Exit:** Enter `exit` at any time to safely terminate the program with a success message.

## 🛠️ Tech Stack
- **Language:** Python 3.x
