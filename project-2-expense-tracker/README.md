# 📊 Personal Expense Tracker (CLI)

A simple and interactive Command Line Interface (CLI) based Personal Expense Tracker built using Python. It allows users to input their daily expenses continuously and calculates the total expenditure in real-time until they decide to exit.

---

## 🌟 Key Features

* **➕ Continuous Expense Input:** Interactively enter expense amounts one by one.
* **💰 Dynamic Total Calculation:** Automatically updates and displays the running total after every entry.
* **🚪 Safe Program Exit:** Type `exit` to safely end the loop and view the final total expense statement.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Version Control:** Git & GitHub
